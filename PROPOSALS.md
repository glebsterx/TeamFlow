## 1. Надёжность и инфраструктура

- 🔴 **S — Персистентные напоминания (закрывает AUD-8).**
  Сейчас `/remind` живёт в `asyncio.create_task` и теряется при рестарте бэкенда. Завести таблицу `reminders(id, task_id, chat_id, fire_at, sent)` + восстановление активных при старте (как `deadline_notifier`). Бонус — открывает повторяющиеся напоминания.

- 🔴 **M — CI на GitHub Actions.**
  Тесты v0.8.23 есть, но не запускаются автоматически. Workflow: `ruff check` + `pytest` (backend) + `vitest` + `tsc --noEmit` (frontend) на каждый PR. Дёшево, ловит регрессии вроде AUD-1 (битый импорт `TELEGRAM_BOT_TOKEN`) до прода.

- 🟠 **S — Расхождение docs vs реальность по миграциям.**
  CLAUDE.md/ARCHITECTURE заявляют Alembic, фактически — ручной идемпотентный список в `migrate.py`. Либо внедрить Alembic, либо зафиксировать в доке, что источник истины — `migrate.py` (чтобы фичи вроде `deleted_at` не уезжали в прод без записи туда — это и был AUD-2).

- 🟠 **S — Docker healthcheck + `/health` уже есть.**
  Добавить `healthcheck:` в compose на `/health`, чтобы рестарт-гард и оркестрация видели реальное состояние, а не «контейнер запущен».

- 🟡 **S — Ротация бэкапов и алерт при сбое.**
  `backup-db.sh` есть; добавить уведомление в Telegram при неудачном бэкапе/нехватке места.

## 3. Безопасность

- 🔴 **M — Закрыть запись без авторизации.**
  Часть write-эндпоинтов доступна без JWT/API-ключа (технический долг из ROADMAP). Провести инвентаризацию и навесить зависимость-гард на мутации. Сейчас любой, кто достучался до API, может менять данные.

- 🟠 **S — Rate-limit на AI-эндпоинты.**
  `/api/ai/*` ходят во внешний LLM за деньги. Добавить простой лимит (per-account / per-minute), чтобы исключить случайный/злонамеренный слив бюджета.

- 🟡 **S — Аудит секретов в логах.**
  В логах виден прокси с паролем (`socks5://glebsterx:...@`). Маскировать креды в `proxy_applied`.

## 4. Telegram-first фичи (сильная сторона продукта)

- 🔴 **M — Inline-кнопки действий прямо в чате.**
  Под задачей в боте — кнопки «Взять», «В работу», «Готово», «+1ч», «Напомнить». Callback уже есть в проекте; это резко ускоряет основной сценарий маленькой команды без захода в веб.

- 🟠 **M — Плановый авто-дайджест в Telegram.**
  Дайджест уже считается для UI/CSV. Добавить расписание (ежедневно утром / по понедельникам) с пушем в чат команды. APScheduler или существующий планировщик.

- 🟠 **S — @упоминания в комментариях → уведомление.**
  При `@username` в комментарии слать пуш/Telegram упомянутому. Дёшево, заметно повышает вовлечённость.
